# DNS Guide (فارسی)

## هدف
راهنمای سریع برای اتصال دامنه سفارشی به تجربه مستاجر (Tenant).

## مراحل کلی

۱. دامنه مورد نظر را از پنل مدیریت دامنه خود خریداری کنید یا به موجودی تبدیل کنید.
۲. در تنظیمات DNS هاست خود، رکوردها را مطابق با جدول زیر وارد کنید.
۳. پس از انتشار DNS، به بخش `Dashboard -> Settings -> Domains` برگردید و دکمه بررسی را فشار دهید.
۴. هنگام فعال شدن دکمه «بررسی»، وضعیت دامنه به `ACTIVE` تغییر می‌کند.

## رکوردهای پیشنهادی برای Vercel

| نوع | نام | مقدار | توضیح |
|-----|-----|-------|-------|
| Apex | @ | 76.76.21.21 | ریشه دامنه به Vercel |
| Apex | www | cname.vercel-dns.com | زیردامنه www (توصیه شده) |
| Subdomain | sub | cname.vercel-dns.com | فقط برای زیردامنه |
| TXT | _vercel | (در پنل Vercel یا strref ظاهر می‌شود) | تأیید مالکیت |

## نکات
- برای apex دامنه‌ها (مثل `example.ir`)، حتما `www.example.ir` را هم ثبت کنید.
- تغییرات DNS معمولاً بین ۵ تا ۶۰ دقیقه زمان می‌برد.
- در صورت خطای `ERROR`، پیام سیستم را بررسی کرده و رکوردهای DNS را دوباره اعمال کنید.
