# Phase 63 — Vercel Custom Domain Automation

This phase connects the SUPER_ADMIN shop-domain manager to the Vercel REST API.

## Scope

- SUPER_ADMIN-only automation from `/[locale]/dashboard/shop-domains`.
- Add a custom domain to the configured Vercel project.
- Check/verify a custom domain against Vercel.
- Remove a custom domain from the Vercel project without deleting the local Bazar Baz mapping.
- Store the resulting local status in `OrganizationDomain`:
  - `ACTIVE` when Vercel reports the domain as verified.
  - `VERIFYING` / `DNS_REQUIRED` while DNS or ownership verification is still pending.
  - `FAILED` when Vercel rejects the operation.
- Display recommended DNS records returned/generated by the automation.
- Write audit logs for domain connect/update/remove and Vercel sync actions.

## Required env

```env
VERCEL_ACCESS_TOKEN=
VERCEL_PROJECT_ID=
VERCEL_TEAM_ID=
# Optional alternative to VERCEL_TEAM_ID
VERCEL_TEAM_SLUG=
# Optional safety switch for local/staging
VERCEL_DOMAIN_AUTOMATION_DRY_RUN=true
```

`VERCEL_ACCESS_TOKEN` and `VERCEL_PROJECT_ID` are required for real mutations. `VERCEL_TEAM_ID` or `VERCEL_TEAM_SLUG` is needed when the project belongs to a team.

## Safety behavior

Set this for local/staging dry-run:

```env
VERCEL_DOMAIN_AUTOMATION_DRY_RUN=true
```

In dry-run mode, dashboard actions still return DNS guidance and update the local row as if a verification flow is pending, but no Vercel mutation is sent.

## Dashboard behavior

The existing SUPER_ADMIN page now includes:

- “Also provision on Vercel” when connecting a domain.
- Per-domain actions:
  - Add to Vercel
  - Check Vercel
  - Remove from Vercel
- DNS record panel after add/check/remove.
- Automation status message when env is missing or dry-run is active.

## API behavior

Central shop-domain API:

```txt
GET    /api/dashboard/shop-domains
POST   /api/dashboard/shop-domains
PATCH  /api/dashboard/shop-domains
DELETE /api/dashboard/shop-domains
```

Vercel action API:

```txt
POST /api/dashboard/shop-domains/[domainId]/vercel
```

Body:

```json
{ "action": "add" }
```

Supported actions:

```txt
add
check
remove
```

All APIs remain SUPER_ADMIN-only.
