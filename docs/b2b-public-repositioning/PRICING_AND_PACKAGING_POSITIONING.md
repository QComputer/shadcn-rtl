# Pricing and Packaging Positioning

This document defines the positioning for Bazar Baz pricing and packages.

## Core Message

Bazar Baz does not have a fixed public price list. Pricing is customized based on:

- نوع کسب‌وکار
- تعداد شعبه‌ها
- حجم سفارش/نوبت
- پیامک/اعلان usage
- سطح پشتیبانی موردنیاز

## Packages

| Package | Target | Position |
|---|---|---|
| شروع | فروشگاه کوچک و کسب‌وکارهای تازه‌تاسیس | Basic online presence |
| رشد | کسب‌وکارهای در حال رشد | Integrated tools for growth |
| حرفه‌ای | کسب‌وکارهای ثابت با حجم مشتری بالا | Advanced management |
| سازمانی / چندشعبه‌ای | franchise و سازمان‌های بزرگ | Centralized enterprise |

## Rules

- Do not claim exact prices if they are not finalized.
- Do not create payment checkout flows.
- Do not implement billing engine in P06.
- All package CTAs should lead to request-demo or consultation.
