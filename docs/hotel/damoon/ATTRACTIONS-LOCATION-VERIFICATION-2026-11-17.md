# Damoon location and attractions verification

Verified 2026-11-17 for the public Damoon contact map and nearby-attractions page. Distances below are approximate driving routes from the hotel map point, rounded to the nearest 0.1 km. They are not travel-time promises; routing and road data can change.

## Hotel origin

- Public address already recorded for Damoon: Shahrekord, North 12 Moharram Street, Basij Square.
- Map point used for route calculations: 32.32657 N, 50.85848 E. [Maps.me Damun Hotel listing](https://maps.me/catalog/lodging/tourism-hotel/country-yrn/city-shhrkhrd-32676699/) gives this point for “Damun Hotel | هتل دامون”. The existing [Waze destination](https://www.waze.com/live-map/directions/damoun-hotel-htl-damwn-shhrkrd?to=place.w.33358147.333319329.15567976) resolves to Damoun Hotel in Shahrekord and displays the reception number 038 3226 1988, matching the site. The public contact address is also listed by [Ealiya](https://www.ealiya.com/hotel/shahrekord-damoon/) and [TikHotel](https://tikhotel.com/hotels/iran/shahrekord/damoon).
- Coordinates are used as a map point, not a surveyed property boundary; directions links open the named Waze pin for the hotel.
