## Phase-level no-go summary

R6.2 stops on ambiguous/non-empty target, incomplete source identity/ledger, unsupported `pg_session_jwt`/`neon_auth` restore semantics, failed restore, adapter mismatch, unresolved media ownership, packaging/secrets issue or lack of approved existing resources. No new database or duplicate service may be created as a workaround. R6.3 stops on any tenant/security failure, broken legacy media URL, missing restart durability, backup restore failure, disabled gates changing unexpectedly, resource breach or unreviewed R3/R5 regression. R6.4 stops unless final writer freeze, backup, media reconciliation, single-writer proof, DNS/traffic owner and post-write rollback reconciliation are all ready and explicitly approved.

## R6.1 scope boundary

No migrations, deployments, disk provisioning, media copies/deletions, DNS changes, service changes, environment updates, database writes or tests are authorized or performed by this register. Root-observed Vercel/Neon/RunFlare facts above include fresh SQL evidence dated 2026-10-24, but must be rechecked before future use. Preserve evidence provenance and do not infer any target emptiness or successful restore from source SQL metadata.
